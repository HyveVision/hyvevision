# Hyve

The official public website for Hyve, a cybersecurity, IT consulting, and cloud
solutions company. Hyve operates under Hyve Vision Inc. Hyve IQ is the product
family; Discover is its first product.

## Local Preview

Open `index.html` directly in a browser. No installation, build, or development
server is required. All runtime assets are stored in this repository. The only
JavaScript updates the copyright year; the page also works with JavaScript disabled.

## GitHub Pages

In the repository's **Settings > Pages**, select **Deploy from a branch**, then
choose **main** and **/ (root)** and save. The root `index.html` is the entry point;
no workflow or build step is needed. The `CNAME` file sets the custom domain to
`hyvevision.com`. Configure the matching DNS records with the domain registrar and
enable HTTPS in Pages once the domain is verified.

## Editing

- `index.html`: page content, metadata, and the copyright-year script.
- `styles.css`: layout, Hyve brand colors, responsive styles, and reduced-motion support.
- `assets/`: supplied Hyve and Hyve IQ Discover logos and favicon.

No analytics, cookies, forms, or third-party runtime requests are used.
